Windows Rust 验证使用独立命名的 1.96.0 工具链：

```powershell
cargo +1.96.0 test --locked --manifest-path src-tauri/Cargo.toml --no-default-features --lib
```

本机已有的 stable 工具链缺失 core 标准库元数据，第一次编译失败；安装独立命名的同版本工具链后通过，没有更改默认工具链。编译缓存放在 Windows 临时构建目录，依赖下载使用 Windows Cargo 缓存。

## Rust 回归覆盖

证书 4 项：首次生成无需代理先启动；重复生成保留身份；并发生成保留同一身份；证书 / 私钥不完整时不覆盖已有文件。

代理 6 项：永不结束的响应立即交还而不预读 body；data、响应头和 trailers 保留；并发响应各归其日志；无关请求 body 不预读且不入日志；目标域名匹配覆盖 CONNECT 并排除相似恶意域名；正文读取失败返回 502，不转发成空请求。

日志 1 项：Authorization、Cookie、Set-Cookie、API Key、COSY 身份和未知自定义头的值不出现在诊断日志；传输元数据可保留。
